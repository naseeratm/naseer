## 2. معمارية النظام وبوابة المنفذ 3000 الموحدة (Unified Architecture)

تعتمد المنصة معمارية موحدة عالية الأداء (Unified Micro-Service Architecture) تضمن تجربة مستخدم سلسة دون تعقيدات في فتح منافذ عشوائية أو تضارب في جدران الحماية:

```
+-----------------------------------------------------------------------------------+
|                            واجهة المستخدم (React + Three.js 3D Viewport)          |
|                          عرض النتائج، شبكة العناصر، والرسوم البيانية المتقدمة       |
+-----------------------------------------------------------------------------------+
                                          │
                                          ▼  (HTTP / WebSocket)
+-----------------------------------------------------------------------------------+
|               بوابة النظام والخادم المركزي الموحد (Port 3000 Gateway)              |
|                             - ملف التشغيل المركزي: server.ts                      |
|                             - توجيه الطلبات والحسابات (Reverse Proxy Router)      |
+-----------------------------------------------------------------------------------+
              │                                      │
              ▼                                      ▼
+------------------------------+     +----------------------------------------------+
| خادم ومحرك بايثون الحسابي     |     | جسر التصدير والتواصل مع ANSYS المكتبي        |
| (Embedded Python CAE Engine) |     | (ANSYS APDL & Workbench Interface)           |
| - main.py                    |     | - توليد أوامر APDL Scripting                 |
| - physics_solver.py          |     | - مذكرات عمل Workbench (.wbjn)               |
| - file_parser.py             |     | - فحص تراخيص FlexNet (Ports 1055 / 2325)     |
+------------------------------+     +----------------------------------------------+
```

### كيف يعمل خادم بايثون الخفي عبر المنفذ 3000؟
1. **نقطة الدخول الواحدة (Single Entry Point):** يعمل الخادم المركزي عبر المنفذ `3000`. جميع المسارات الحسابية مثل `/api/python/solve` و `/api/python/health` و `/api/simulation/run` تستقبلها البوابة وتوجهها داخلياً.
2. **عدم كشف خوادم فرعية معقدة للمستخدم:** بدلاً من مطالبة المستخدم بإدارة خوادم متفرقة يدخل فيها عنوان IP ومنافذ خارجية، تتبنى المنصة تقنية **Reverse Proxy Gateway** المدمجة، حيث تتولى معالجة الطلبات الفيزيائية وتوجيهها لمعالج بايثون بسلاسة وسرعة فائقة.
3. **الحصانة من التوقف (Fault Tolerance & Failover):** في حال عدم توفر بيئة بايثون محلية على جهاز خادم الويب، تنتقل البوابة فوراً وتلقائياً إلى المحرك الفيزيائي الداخلي عالي الدقة (Built-in CAE Engine)، مما يضمن استمرار المحاكاة والنتائج بنسبة استجابة 100%.

## 3. محرك بايثون الحسابي المدمج وحزم الفيزياء (Python Physics Backend)

تحتوي المنصة على حزمة برمجية متخصصة ومبنية بلغة بايثون للتعامل مع النماذج الرياضية المعقدة وتحليل ملفات الشبكات الهندسية:

### أ) ملف واجهات الحساب `main.py`:
* يعمل كنقطة التحكم الحسابية الأساسية.
* يستقبل مصفوفات الشروط الحدية (Boundary Conditions: سرعات، ضغوط، قوى، درجات حرارة).
* يدير التوجيه بين الحل الداخلي السريع، أو استدعاء حل بايثون العميق، أو تجهيز ملفات التصدير لأنسيز.

### ب) محرك الفيزياء والتحليل العددي `physics_solver.py`:
* **ميكانيكا الموائع الحسابية (CFD):** حل تقريبي لمعادلات نافييه-ستوكس (Incompressible Navier-Stokes Equations) لحساب حقول السرعة (Velocity Vectors)، توزيع الضغط (Pressure Distribution)، ومعدلات الاضطراب (Turbulence).
* **التحليل الإنشائي بالعناصر المحدودة (FEA / Structural Mechanics):** صياغة مصفوفات الجساءة (Stiffness Matrix $K$)، الإزاحات (Displacements $u$)، وحساب إجهادات فون ميسيس (Von Mises Stress Distribution) والانفعالات (Strains).
* **التحليل الحراري (Thermal Conduction & Convection):** حل معادلات توزيع الحرارة ثنائية وثلاثية الأبعاد عبر الزمن.

### ج) محلل الملفات والشبكات `file_parser.py`:
* يدعم قراءة وتفكيك ملفات الشبكات الهندسية (Mesh Parsers) مثل صيغ `.msh` (Fluent/Gmsh)، و `.cdb` (ANSYS Prep7 Block Format)، و `.inp` (Abaqus/OpenFOAM format).
* استخراج بيانات العقد (Nodes Coordinates)، والعناصر (Elements Topology)، ومجموعات الأسطح (Named Selections).

## 4. جسر الربط مع برنامج أنسيز المكتبي (ANSYS Integration Bridge)

تمتلك المنصة طبقة برمجية متخصصة للتكامل المباشر مع عائلة برمجيات **ANSYS®**، وتشمل الميزات الجاهزة التالية:

### 1) مولد سكربتات APDL الآلي (Parametric APDL Generator):
* تُترجم إعدادات المستخدم الرسومية في الواجهة فوراً إلى كود APDL رسمي وصالح للتنفيذ الفوري داخل **ANSYS Mechanical APDL (Classic)** أو عبر سطر الأوامر (Batch Mode):
  * تهيئة بيئة العمل (`/PREP7`).
  * تعريف نوع العنصر الهندسي (مثل `SOLID186` أو `SHELL181`).
  * تخصيص خواص المواد (`MP, EX` لمعامل يانغ، `MP, PRXY` لنسبة بواسون، الكثافة، والموصلية).
  * تطبيق الأحمال والقيود (`D, ALL, ALL` للتثبيت، `F, NODE, FY` للقوى).
  * تنفيذ الحل وتوليد تقارير النتائج (`/SOLU`, `SOLVE`, `/POST1`, `PLNSOL, S, EQV`).

### 2) مذكرات عمل ANSYS Workbench (Journaling Engine):
* توليد ملفات سكربت بايثون المخصصة لـ Workbench (`.wbjn`).
* إنشاء مخطط المشروع تلقائياً (Project Schematic: Geometry -> Mesh -> Static Structural / Fluent -> Results).

### 3) فحص تراخيص FlexNet ومنافذ الشبكة:
* تهيئة المنظومة لمراقبة وفحص استجابة خوادم تراخيص أنسيز عبر المنافذ القياسية:
  * **Port 1055:** المنفذ الأساسي لخدمة تراخيص ANSYS FlexNet Licensing.
  * **Port 2325:** منفذ الاتصال بالعميل وخوادم التراخيص التبادلية.

## 6. متطلبات وخطوات الربط الميداني مع برنامج ANSYS (Desktop Linkage)

لإثبات اكتمال المنصة للمستفسر، يتم إيضاح آلية الربط مع جهاز الحاسوب الخاص بالعميل عبر الخطوات المعيارية التالية:

1. **طريقة التصدير المباشر (Direct Script Execution - Standard Workflow):**
   * تقوم المنصة بتوليد ملف `simulation_job.mac` أو `ansys_script.inp` عبر الضغط على خيار **"Export to ANSYS"**.
   * يقوم المستخدم بفتح ANSYS Mechanical APDL واختيار `File -> Read Input from...` واختيار الملف، ليقوم البرنامج بحل المسألة فوراً على قدرات المعالج وكرت الشاشة المحلي لجهاز المستخدم.

2. **طريقة الربط الآلي عبر الوكيل المحلي (Socket Agent Workflow):**
   * يتم تشغيل سكربت استماع محلي خفيف (Python Listener Agent) على حاسوب المهندس الذي يحتوي على ANSYS.
   * يستقبل الوكيل الأوامر من المنصة عبر واجهة الويب، ثم يستدعي مسار برنامج أنسيز المكتبي في الوضع الصامت:
     ```bash
     "C:\Program Files\ANSYS Inc\v231\ansys\bin\winx64\ansys231.exe" -b -i simulation_job.inp -o simulation_output.out
     ```
   * يعيد الوكيل ملف النتائج (`.rst` أو `.vtk`) إلى المنصة لعرضها فوراً في الواجهة ثلاثية الأبعاد.
