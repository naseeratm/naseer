# ANSYS Engineering WorkBench - منصة التحليل والمحاكاة الهندسية الشاملة

تحويل المنصة من قالب أكاديمي خاص بالأطروحات إلى بيئة عمل هندسية وصناعية متكاملة ومستمرة للمحاكاة والتحليل متعدد المجالات (Multiphysics CFD & FEA)، مع دعم استيعاب كافة أنواع الملفات الهندسية، والبرمجية، والجداول، والصور، ودمج محرك حسابي فيزيائي رقمي حتمي دقيق يحاكي نتائج أنسيز بدقة متناهية، ونظام متطور لإدارة مجمّع المفاتيح (Multi-Key Pool) والتدوير التلقائي مع محرك محلي بديل يضمن استمرارية العمل دون انقطاع.

## 1. Overview & Core Concept

### What It Does
منصة هندسية وصناعية متكاملة تعمل كبديل هندسي تفاعلي متقدم لبيئة ANSYS، تتيح:
1. **استقبال ومعالجة شاملة لكافة أنواع الملفات الهندسية** (سكربتات بايثون `.py`، سكربتات أنسيز APDL وجورنال `.mac, .jou, .inp, .cdb`، جداول إكسل `.xlsx, .csv`، وثائق وورد وبي دي إف `.docx, .pdf`، وصور المخططات الهندسية والـ CAD بجميع الامتدادات) مع حقل مخصص لتوجيهات وملاحظات المهندس لضبط الحل.
2. **محاكاة فيزيائية رقمية حتمية (Deterministic Multi-Physics Solver)** تطبق حلولاً دقيقة لميكانيكا الموائع (CFD)، التحليل الإنشائي (FEA)، وانتقال الحرارة (Thermal Analysis)، وحسابات دقيقة لمؤشر تقارب الميش (Roache GCI) بدون تخمينات أو نتائج احتمالية عشوائية.
3. **مستكشف تفاعلي للكونتورات والميش (2D/3D Field Visualizer)** لرسم خرائط السرعة، الضغط، إجهادات فون ميسيس، وتدفقات الحرارة مع مسابر رقمية لحظية وتدقيق جودة عناصر الميش (Skewness, Aspect Ratio, Orthogonality).
4. **وحدة إدارة المحركات ومجمّع المفاتيح (Zero-Downtime Engine & Multi-Key Pool Console)** تتيح إدخال مفاتيح متعددة وتدويرها تلقائياً مع خيار التشغيل المباشر للمحرك الفيزيائي المحلي عند نفاد الحصص أو في بيئات العمل المعزولة.

### Target Audience & Persona
مهندسو الميكانيكا، الطيران، الإنشاءات، الطاقة، الكيمياء، والباحثون في مراكز التطوير الصناعي والأكاديمي الذين يحتاجون لحل ومراجعة وتحليل نماذج CFD/FEA بدقة ومطابقتها مع الواقع التجريبي وإصدار تقارير هندسية معتمدة.

### Key Value
تحليل فوري ونمذجة دقيقة لكافة مخرجات وسكربتات المحاكاة دون الحاجة لتثبيت برمجيات أنسيز الضخمة على الجهاز، مع ضمان استمرارية العمل 100% بدون أي توقف ناتج عن حدود الاستخدام أو حصص الواجهات البرمجية.

## 3. Key Product Decisions & Trade-Offs

### Decision 1: استبدال التخمينات العشوائية بمحرك فيزيائي حتمي (Deterministic Physical Formulation)
- **النهج**: كتابة خوارزميات رياضية دقيقة في `physicsEngine.ts` لحل:
  - ديناميكا الموائع: معادلات نافييه-ستوكس ثنائية الأبعاد، هبوط الضغط وفق دارسي-فايسباخ، وسرعات الطبقة الجدارية لـ بوازي وبلاسيوس.
  - التحليل الإنشائي: إجهادات فون ميسيس وعزوم الانحناء وحساب مصفوفات التشوه المرن ونظرية الأعمدة لأويلر وتيموشينكو.
  - انتقال الحرارة: معادلة فورييه للتوصيل ثنائي الأبعاد وتوزيعات درجات الحرارة الخطية وغير الخطية.
  - مؤشر روتش: حساب دقيق لمعاملات $GCI_{12}, GCI_{23}$ ومعدل التقارب الظاهري $p$ ونسبة الخطأ الاستقرائي لريدشاردسون.
- **السبب**: استجابة لشرط المستخدم الصارم بأن تكون النتائج هندسية حقيقية وليست مجرد نصوص تخمينية أو احتمالية.

### Decision 2: نظام مجمّع المفاتيح والتبديل للمحرك المحلي (Zero-Downtime Multi-Key Architecture)
- **النهج**:
  1. توفير واجهة مخصصة لإدارة مجمع المفاتيح (Key Pool Manager) تتيح إضافة عدة مفاتيح احتياطية، وتخزينها بأمان محلياً في المتصفح وتمريرها في ترويسات الطلبات الموجهة للمسارات الوسيطة الخادمة `/api/*`.
  2. توفير تدوير تلقائي للمفاتيح عند استلام كود 429 (Too Many Requests / Quota Exceeded).
  3. تفعيل خيار **"المحرك الفيزيائي المحلي الخالص"** (Pure Deterministic Engine) كخيار دائم يمكن تفعيله يدوياً أو تلقائياً بنقرة واحدة لتنفيذ كافة الحسابات والتحليلات ورسم الكونتورات محلياً 100% دون الحاجة لأي مفتاح خارجي.
- **السبب**: يمنع توقف المنصة نهائياً ويوفر استقلالية هندسية كاملة للمستخدم في بيئات العمل المتواصلة.

### Decision 3: محطة الرفع الهندسية الشاملة (Universal Multi-Format Ingestion Station)
- **النهج**: توسيع معالج الرفع ليستقبل ملفات متعددة في وقت واحد وبكافة الامتدادات:
  - الأكواد والسكربتات: `.py`, `.mac`, `.inp`, `.jou`, `.dat`, `.cdb`, `.m`, `.txt`
  - البيانات والمصفوفات: `.xlsx`, `.csv`, `.tsv`, `.json`
  - الوثائق والمواصفات: `.docx`, `.pdf`, `.doc`, `.md`
  - المخططات والصور الهندسية: `.png`, `.jpg`, `.jpeg`, `.svg`, `.webp`, `.bmp`, `.step`, `.stl`
  - مع نافذة لمعاينة وتحليل الصور الهندسية رقمياً، وحقل لإدخال الملاحظات والتوجيهات والشروط الهندسية المقيدة للنموذج.

### Component Structure & Plan
1. **Core Types (`src/types/thesis.ts`)**: ترقية النماذج لتشمل مصطلحات بيئة العمل الهندسية العامة (General Engineering Project)، دعم مفاتيح المحرك وحالات المجمع (Key Pool state, Engine mode, Ingested File artifacts, CAD image items).
2. **Deterministic Physics Engine (`src/utils/physicsEngine.ts`)**: توسيع المحرك الرياضي ليضم معادلات نافييه-ستوكس المحلولة عددياً، حسابات الإجهادات ثلاثية الأبعاد، معادلات الاحتكاك والطبقة الجدارية، وحسابات GCI الحتمية.
3. **Universal Ingestion Modal (`src/components/ScriptUploaderModal.tsx`)**: إعادة بناء كاملة لدعم سحب وإفلات ملفات متعددة من أي امتداد، قراءة محتويات النصوص والجداول ومعالجة الصور الهندسية، مع واجهة إدخال التوجيهات الهندسية.
4. **Engine & Key Pool Console (`src/components/KeyPoolModal.tsx`)**: إضافة مكون جديد مخصص لإدارة مجمّع المفاتيح، اختبار صحتها، مراقبة حالة الاستهلاك، والتبديل المباشر بين الوضع الهجين والوضع المحلي الحتمي.
5. **Redesigned Header & Navigation (`src/components/Navbar.tsx`)**: إزالة المسميات الطلابية وتحويلها إلى شريط تحكم صناعي احترافي يتضمن مؤشر حالة المحرك، زر مجمع المفاتيح، زر الرفع الشامل، وتبديل المشروعات الهندسية.
6. **Main Workspace Views**:
   - `OverviewTab.tsx`: كونسول التحكم بالنموذج الهندسي والمعادلات الحاكمة والشروط الحدية.
   - `MeshStudyTab.tsx`: فحص شبكة الميش، حسابات مؤشر روتش (GCI)، ومقاييس الجودة الأكاديمية والصناعية.
   - `ContoursTab.tsx`: مستعرض الحقول والمجالات التفاعلية مع مسابر رقمية وفلترة الحقول والسرعات.
   - `ValidationTab.tsx`: مقارنة ومطابقة المحاكاة مع المراجع التجريبية وحسابات $R^2$ وشريط خطأ ASME.
   - `TablesTab.tsx`: الجداول الحسابية ومصفوفات النتائج مع إمكانية التصدير.
   - `ThesisReportTab.tsx`: التقرير الهندسي الشامل المعتمد للمشروع.
   - `SupervisorAssistantDrawer.tsx`: تحويله إلى **مستشار التحليل الهندسي والمحاكاة المتقدم (Senior Engineering Analysis Consultant)**.
7. **Server Proxy (`server.ts`)**: دعم استلام مفاتيح المستخدم الديناميكية عبر ترويسات الطلب لتنفيذ التدوير بسلاسة مع دعم الموديلات الموصى بها ومعالجة أخطاء الحصص بأمان.
